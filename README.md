### Project Description:

The project aims to entertain with mathematical components, using formulas with randomly chosen integers for randomized variables, and so on. The project itself utilizes a Class system, or a Character that adds to certain attributes and have their own unique variables, to further add a randomness factor and a bit of a twist. The project will also have the Enemies, or the Monsters, which also have their own unique formulas and variables and are designed to go against the user, acting as obstacles or roadblocks. There will also be a list system, functioning as the Inventory of the player, so that the player may use Items they acquire along their playthrough/runthrough of the code to further manipulate target variables. The target users are mostly for children ages 8 and above, but adults of any age may also play.

### Goals:

- Objective 1: Create the character classes (Warrior, Mage, Rogue, and Enemy) using encapsulation, inheritance, and method overriding.
- Objective 2: Build an inventory system that lets players use, equip, and drop items, with item stacking and a slot limit.
- Objective 3: Build a turn-based battle system with a Pokémon-style damage formula, (random damage rolls), and critical hits.
- Objective 4: Test the game through full playthroughs, fix bugs, and balance character and enemy stats so the game is challenging but fair.
